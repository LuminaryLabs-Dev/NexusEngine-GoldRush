# Gameplay Loop And UI Feedback

Status: active

## Purpose

Preserve user corrections about the first sequence, lobby, interaction surface, and player-facing UI.

## Feedback

- Lobby should not present Crew, Posse, and Outfit as large selection cards; it should use a compact dropdown/group-type control.
- Party lobby is up to four players by code; leader loads into the larger mass match.
- Start screen should play Gold Rush audio or approved fallback cues, then enter lobby.
- The lobby should feel like a battle-royale staging screen with a real 3D rotatable character.
- Start should enter a loading scene, not instantly teleport to the match.
- Loading scene should show the train riding up, door opening, player boarding, player locking to train, and train leaving with camera follow.
- Main game should be immersive full 3D; debug overlays should not be the main player experience.
- Interaction should focus on visible objects and a player-facing action surface, not hidden direct helper actions.

## Required Proof

- Lobby screenshot proves compact controls and 3D character.
- Train proof shows arrival, door cue, boarding, train lock, and departure.
- Run proof shows player action prompts for mine/carry/cashout.
- Results proof comes from receipt-backed gameplay state.
