# AAA 100 Step Audits

Status: active docs-only

## Purpose

This folder contains one hardening audit for each GoldRush AAA roadmap step. The audits are meant to run before and after implementation so the project keeps finding edge cases, deployment issues, fake progress, and proof gaps.

## Use Rule

A roadmap row cannot move to resolved from documentation alone. It needs current implementation evidence, validator proof, human-view proof when player-facing, public proof when deploy-facing, and sanitized reports when anything is retained.
