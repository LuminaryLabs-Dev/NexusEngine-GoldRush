# Reference Benchmark Matrix

Status: active docs-only

| Reference | Observed pillar | GoldRush implication |
| --- | --- | --- |
| Apex | 60-person BR, legends, modes, massive maps | 60-player goal must be product-visible, squad identity must be legible, map and mode readiness cannot be hidden behind internal shards |
| PUBG | zone pressure shapes movement, positioning, combat timing, survivor flow, and risk choices | GoldRush final rush/pressure must tune rotations, extraction greed, density, and encounter distance instead of only showing warnings |
| Hunt | bounty value, extraction fight, loss, atmosphere, and audio-readable danger | GoldRush gold/cashout/combat/audio must create risk decisions and world-readable threat |
| Game engine feature scan | runtime, rendering, physics, audio, asset pipeline, validation, deployment, and tooling surfaces | GoldRush should not become an engine, but must not omit essential feature surfaces needed by its game loop |
