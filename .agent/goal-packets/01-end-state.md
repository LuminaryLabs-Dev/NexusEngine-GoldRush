# End State Goal

Status: active

## Purpose

Capture the full user-requested completion shape so future passes do not redefine success around a smaller proof.

## End State

`NexusEngine-GoldRush` is finished only when it is a high-fidelity wild-west extraction battle royale that runs as a browser-deployable game and uses NexusRealtime-style kit composition as its real architecture.

## Required Outcomes

- The game has one unified Gold Rush identity.
- Both old Gold Rush Unity versions are represented in the unified browser game.
- Perspective shifts by state: exploration/extraction uses broad over-the-shoulder readability; combat uses closer combat-focused camera/input/readability.
- NexusRealtime is the core runtime contract.
- NexusRealtime-Kits and ProtoKits supply reusable domain behavior where appropriate.
- GoldRush custom kits own game-specific rules, content, and orchestration.
- Legacy assets/audio are copied into this repo through the approved raw/sanitized/review/promotion pipeline before runtime use.
- The public Pages link loads the current game from the `Build` branch.
- Local and public states have retained screenshots; videos are retained when diagnosing motion.

## Not Complete Until

- Approved runtime assets replace placeholder slots.
- Character rig and animations are game-readable, not just placeholder proof.
- Combat is playable and legible, not only represented in results.
- Mining/cashout is a player-facing interaction loop, not direct helper completion.
- Local/public proof covers the full loop without hiding critical steps behind debug-only shortcuts.
