# Creator And Influencer Packet

## Simulation Summary

A creator will decide quickly whether Gold Rush creates streamable moments.

## Expected Outcome

- Clear "we got greedy" moments.
- Ambushes visibly shift camera/audio/animation state.
- Cashout creates relief and score proof.
- Towns and gold zones create named places for callouts.

## Failure Signs

- The clip looks like a prototype grid with UI counters.
- Combat has no audiovisual shift.
- Gold collection has no visible stakes.
- No named places or routes for narration.

## Evidence Needed

- Public browser clip or screenshot sequence:
  - generate rooms.
  - mine gold.
  - ambush.
  - cash out.
- HUD shows carried, banked, scene, audio, anim, town/patch context.

## Recommended Next Action

Add more named place descriptors and expose the current town/path/gold-zone in the debug HUD.
