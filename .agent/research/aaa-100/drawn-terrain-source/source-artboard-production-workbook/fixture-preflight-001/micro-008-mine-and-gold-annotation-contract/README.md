## Purpose

Break the mine and gold annotation atom into micro-steps small enough for the first future terrain resource, mining, cargo, scoring, and player-proof implementation. This packet is still docs-only.

## Rule

The terrain source must own mine sites, gold seams, resource node ids, yield tags, approach workspaces, interaction anchors, consumer echoes, negative cases, and stale-proof behavior before mining markers, gold visuals, hold actions, cargo, scoring, bots, or public proof can claim resource gameplay is authored.

## Why This Matters

GoldRush is a gold extraction game. If mines and gold seams are not source-owned, the core loop remains a prototype trick: a player presses an input near a marker and receives score. Authored mine and gold annotations make the loop inspectable, replayable, scalable, and compatible with future digital asset protokits.
