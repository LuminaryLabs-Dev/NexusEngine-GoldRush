## Purpose

Break the cashout and extraction annotation atom into micro-steps small enough for the first future terrain-authored extraction, cashout, receipt, scoring, and proof implementation. This packet is still docs-only.

## Rule

The terrain source must own cashout sites, extraction radii, deposit anchors, return routes, risk and contest tags, readability tags, cashout queries, renderer marker echoes, extraction hold echoes, receipt/results echoes, negative cases, and stale-proof behavior before cashout markers, extraction holds, receipts, scoring, replay, bot behavior, or public proof can claim authored extraction correctness.

## Why This Matters

GoldRush cannot become a high-fidelity extraction battle royale if the cashout destination is only a UI marker or hardcoded point. Players need readable destination silhouettes, safe and risky routes back from mines, contestable hold space, clear deposit anchors, and receipts that prove where the gold was actually banked.
