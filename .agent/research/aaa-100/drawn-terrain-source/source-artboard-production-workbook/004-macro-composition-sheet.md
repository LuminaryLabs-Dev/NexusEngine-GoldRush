# Macro Composition Sheet

Status: active docs-only

## Purpose

Define the drawn map as a readable place, not as noise.

## Required Composition

```txt
horizon mesas
|-- playable basin floor
|-- central mountain blocker
|-- rail corridor and station/depot shelf
|-- frontier town shelf
|-- mine shelf and cave mouths
|-- wash routes and dry creek beds
|-- gold seam risk lanes
|-- cover and ambush pockets
`-- extraction/cashout landmarks
```

## Player-View Needs

| View | Must be readable |
| --- | --- |
| Title/run establishing view | terrain silhouette and frontier identity |
| Loading-yard train view | rail path, boarding point, destination hint |
| Spawn view | first mine direction and landmark hierarchy |
| Mine view | claim target, route out, cover nearby |
| Carry view | cashout landmark, risky shortcut, threat lane |
| Combat view | cover, flank, high ground, retreat route |
| Cashout view | extraction radius, interrupt danger, landmark shape |
| Results replay view | route story and extracted value |

## Hard Rule

The central mountain should be an obstacle players route around or through, not just a huge visual mound.
