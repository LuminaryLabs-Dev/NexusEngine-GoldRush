# Player Space Design Contract

Status: active docs-only

## Purpose

Define how the terrain source supports actual play, not only scenery.

## Player View Requirements

Each major view should expose readable foreground, midground, destination, and danger.

| Space | Must show | Why it matters |
| --- | --- | --- |
| Spawn | train memory, route start, first mine hint | player orientation |
| Mine approach | gold cue, cover, escape path | first objective |
| Carry route | cashout direction, risky shortcut, ambush cover | extraction tension |
| Combat lane | cover, flank, elevation, retreat | fair fights |
| Town shelf | landmarks and loot/cashout affordances | identity and density |
| Central mountain | blocker, route split, strategic silhouette | macro navigation |
| Final rush | pressure direction and fallback routes | battle-royale pacing |

## Camera Rule

The over-the-shoulder camera should never be the only source of readability. The map must be readable from player eye level, route guidance screenshots, and public proof captures.
