# Free Toon Asset Candidate Atomic Packets

Status: active docs-only

## Purpose

Break the free toon asset candidate expansion into implementation-sized gates. Each candidate set has six atoms: source evidence, license provenance, format integrity, toon style adaptation, protokit contract, and proof/promotion block.

## Rule

No atom imports or approves assets. These packets define the minimum evidence that must exist before later implementation can safely move a candidate through the pipeline.

## Count

- Candidate sets: 8
- Atoms per set: 6
- Atomic packets: 48
