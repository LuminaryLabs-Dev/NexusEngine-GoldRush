# Staging Mode Taxonomy

Status: active docs-only

## Purpose

Keep all non-production modes explicit so future reports do not overclaim.

## Modes

| Mode | Human count | Bot count | Simulated entity count | Allowed claim |
| --- | --- | --- | --- | --- |
| practice | 1 | 0-3 | 0 | One player can learn and rehearse controls. |
| training-yard | 1 | 0-6 | 0 | One player can rehearse mechanics safely. |
| bot-fill | 1-4 | 1-59 | 0-59 | Bot pressure and squad-like flow can be rehearsed. |
| twenty-player-sim | 1-4 | 0-19 | 20 | 20-player state shape can be sampled. |
| sixty-player-sim | 1-4 | 0-59 | 60 | 60-player state and budget can be simulated. |
| peer-party-local | 2-4 browser contexts | optional | optional | Party sync can be tested locally. |
| public-smoke | 1 browser | optional | optional | Published build matches local proof scope. |
| future-live | 2-60 live clients | optional | optional | Live networking readiness can be claimed only with live client proof. |
