# Staging Fakeout Register

Status: active docs-only

## Register

| Scenario | Fakeout to prevent |
| --- | --- |
| Staging Mode Registry | A hidden debug flag changes behavior but no player, tester, or validator can see which mode is active. |
| Single Player Practice Loop | A solo route reaches results only through direct completion helpers or teleports. |
| Training Yard Onboarding | Tutorial text exists but the player never performs the actual controls in-world. |
| Bot Roster Seeding | Bot count is a number in state but bots have no spawn, team, behavior, or receipt identity. |
| Bot Behavior Archetypes | Bots exist but only stand still, chase blindly, or deal hidden damage. |
| Dummy Squad Simulation | The report says squad play but every entity acts as isolated singletons. |
| Twenty Player Dress Rehearsal | A 20-player count exists but no update budget, event volume, or visible pressure is measured. |
| Sixty Player Scale Harness | A single-browser proof is described as live 60-player readiness. |
| Room Partition Load Test | Partition math passes but player handoff, reconnect, or party identity is untested. |
| Scenario Seed Library | Tests are deterministic only because hidden globals or local browser state persist. |
| NexusSimulator Contract | The simulator proves internal calls that no real player can perform. |
| Playwright Human Staging Proof | A report captures state but no screenshot shows what the player sees. |
| Network Failure Rehearsal | Happy-path party proof passes but failures lock train boarding or corrupt match receipts. |
| Combat Pressure Rehearsal | Combat receipts exist but no player-facing fight, cover, hit, or recovery readability exists. |
| Economy Reward Rehearsal | Results show a score but the score does not derive from mined, carried, contested, and extracted receipts. |
| Public Private Proof Boundary | Local proof is cited as public proof or simulator proof is cited as live multiplayer proof. |
| Restart With New Knowledge | Failures are fixed ad hoc and future agents repeat the same false assumptions. |
| Release Candidate Staging Gate | Build passes while the title-to-results loop, staging mode, or public proof is stale. |
