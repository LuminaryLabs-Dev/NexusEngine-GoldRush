# Run Value Ladder - Player Loop

Status: planned docs-only
System: 01
Domain: gameplay/economy/match

## Player Question

What is worth doing right now and why should I risk it?

## Acceptance

- The player can see why the system matters.
- The result screen explains the outcome.
- Practice/staging/live eligibility is clear.
- The system does not crowd the first-screen hero action.
- The system has a matching receipt and replay summary.

## Human-View Proof

Human-view proof shows a player identify a valuable target, mine it, carry it, risk it, extract it, and see payoff.
