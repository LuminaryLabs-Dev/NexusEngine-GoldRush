# Tuning Data Matrix

Status: active docs-only

## Purpose

Define balance values that should eventually become versioned data rather than scattered constants.

| Tuning area | Example values | Owner kit | Proof need |
| --- | --- | --- | --- |
| Gold source | value, spawn density, depletion | n:goldrush:gold-economy | value ledger and route proof |
| Cargo burden | speed, noise, posture, capacity | n:goldrush:gold-carrying | movement and threat proof |
| Threat pressure | alertness, distance, damage, cover | n:goldrush:ambush-pressure | warning and counterplay proof |
| Cashout | timer, radius, contest, modifier | n:goldrush:cashout-sites | hold and results proof |
| Final rush | phase, pressure, modifier, route close | n:goldrush:final-rush-pressure-economy | timeline proof |
| Progression | eligibility, cap, unlock type | n:goldrush:progression-boundary | mode matrix proof |
| Bot fill | bot count, difficulty, reward flag | n:goldrush:bot-fill-reward-boundary | staging proof |
| Release | ruleset id, deploy id, proof id | n:goldrush:economy-release-policy | local/public proof |
