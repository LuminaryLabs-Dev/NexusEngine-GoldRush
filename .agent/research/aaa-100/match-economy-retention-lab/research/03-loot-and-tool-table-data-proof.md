## Data And Proof

- Data seed: item id, category, rarity, role, spawn rule, carry burden, use effect, counterplay, approved asset slot.
- Event seed: loot.spawned, loot.seen, loot.picked, loot.used, loot.dropped, loot.depleted.
- Validator target: Loot table validator proves every item has role, rarity, spawn rule, effect, counterplay, and presentation placeholder..
- Human-view proof: Player-view proof shows at least one mining tool, movement tool, combat item, and extraction utility with distinct silhouettes..
- Public proof must include the economy/progression ruleset id when the behavior is deploy-facing.
