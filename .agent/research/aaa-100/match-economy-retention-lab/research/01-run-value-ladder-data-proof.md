## Data And Proof

- Data seed: value tier, source type, carry risk, extraction value, score value, replay tag, pacing band.
- Event seed: value.source.spawned, value.claimed, value.carried, value.extracted, value.lost, value.summarized.
- Validator target: Simulate a run and prove every value gain/loss has source, carry, extraction, score, and replay receipts..
- Human-view proof: Human-view proof shows a player identify a valuable target, mine it, carry it, risk it, extract it, and see payoff..
- Public proof must include the economy/progression ruleset id when the behavior is deploy-facing.
