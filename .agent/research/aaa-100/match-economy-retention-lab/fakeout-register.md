# Economy Fakeout Register

Status: active docs-only

| Fakeout | Why it is dangerous | Required hardening |
| --- | --- | --- |
| Bigger score | Does not prove value, risk, loss, or replayability. | Link source, carry, cashout, score, and replay receipts. |
| Gold count only | Hides mined, carried, lost, banked, and spendable values. | Split match, carried, extracted, banked, and meta gold. |
| Loot spam | Adds clutter without decision value. | Require item role, rarity, counterplay, and proof. |
| Progression numbers | Looks deep while core loop may remain weak. | Keep progression optional and mode-gated. |
| Bot-fill rewards | Can imply live multiplayer proof. | Label bot, simulated, private, and public rewards separately. |
| Cosmetic identity | Can blur approval boundaries or imply power. | Separate cosmetic slots from gameplay effect slots. |
| Old public rules | Public build may run stale balance. | Require economy ruleset id in local and public proof. |
| Challenge grind | Daily tasks can bury the fun loop. | Keep challenges optional and tied to fun core actions. |
