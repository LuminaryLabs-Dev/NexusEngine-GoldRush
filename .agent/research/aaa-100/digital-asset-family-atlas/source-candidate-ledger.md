# Digital Asset Candidate Source Ledger

Status: active docs-only

## Purpose

Track current free/CC0-friendly source channels as candidates only. This ledger does not approve or import assets.

## Sources

| Source | URL | Useful for | Gate before use |
| --- | --- | --- | --- |
| Kenney | https://kenney.nl/ | lightweight toon game assets, UI, audio, simple 3D forms | per-asset package, license, provenance, conversion, human review |
| Quaternius | https://quaternius.com/ | low-poly 3D models, characters, buildings, nature, vehicles | per-pack license/provenance, format check, scale proof |
| KayKit | https://kaylousberg.com/game-assets | toon characters, props, resources, blocky forms, GLTF/FBX-friendly packs | item-level page, free tier, license, format, style fit |
| Poly Pizza | https://poly.pizza/ | GLB/GLTF delivery for CC0 low-poly models such as Quaternius bundles | original creator check, license check, direct download proof |
| Poly Haven | https://polyhaven.com/ | CC0 HDRIs, textures, material/reference models | toon adaptation, performance budget, source proof |
| OpenGameArt | https://opengameart.org/ | community assets, textures, music, SFX, 3D art | item-level license review and provenance; do not assume all assets are CC0 |
| Freesound | https://freesound.org/ | one-shot foley, ambience, interaction SFX | CC0-only filter, item-level license screenshot, author/source record |
| Pixabay | https://pixabay.com/sound-effects/ | fallback royalty-free audio search | not CC0 default; content-license review required before use |

## Rule

This ledger is research only. Runtime promotion still requires the existing GoldRush approval and proof gates.
