# Abuse And Sanity Policy

Status: active

## Purpose

Define the minimum future boundary between untrusted clients and authoritative match facts.

## Client May Request

- Move input.
- Aim input.
- Interact input.
- Fire input.
- Cover input.
- Cashout attempt.

## Client May Not Decide Alone

- Gold awarded.
- Damage accepted.
- Cargo stolen or dropped.
- Extraction completed.
- Final score.
- Match result.

## Rejection Reasons

- command too fast.
- impossible distance.
- stale sequence.
- duplicate receipt.
- wrong phase.
- missing authority epoch.
