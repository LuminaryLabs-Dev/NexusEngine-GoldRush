# Proof Boundary Policy

Status: active

## Policy

Every retained report must label what kind of networking it actually proved.

## Proof Labels

- local-solo-proof.
- same-browser-peer-proof.
- same-machine-peer-proof.
- public-pages-transport-proof.
- simulator-scale-proof.
- bot-staging-proof.
- future-live-peer-proof.
- future-live-60-proof.

## Rejection Rule

A report that lacks peer count, machine count, human count, bot count, topology, and proof tier cannot be used for network milestone claims.
