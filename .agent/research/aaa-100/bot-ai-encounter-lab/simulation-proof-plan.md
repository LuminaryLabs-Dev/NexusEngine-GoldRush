# Simulation Proof Plan

Status: active

## Proof Ladder

1. CLI contract proof for role taxonomy and roster labels.
2. NexusSimulator proof for 20 and 60 simulated actor ticks.
3. Local browser proof for one player plus bots using the real terrain and action surface.
4. Public Pages proof for the same staged route.
5. Video proof only for motion, timing, pulsing, train, or combat readability.
6. Future live proof with real peers remains separate.

## Required Report Fields

- run id.
- mode id.
- proof tier.
- human count.
- bot count.
- simulated count.
- scene path completed.
- terrain mismatch max.
- encounter beats observed.
- mining/cargo/cashout receipts.
- combat threat/readability receipts.
- fakeout flags.

## Acceptance

A run can pass staging only when it completes title -> lobby -> train -> spawn -> move -> mine -> carry -> threat -> cashout -> results with proof labels and no helper-only completion.
