# Bot Mining And Cargo Proof Plan

Status: planned

## CLI Proof

- Validate schema shape.
- Validate reset.
- Validate events.

## Human-View Proof

Bot cargo changes movement, threat value, score receipts, and visible dropped-gold opportunities.

## Edge Cases

- Reset during scene transition.
- Public proof with bot labels.
- Local proof with no helper completion.
- Low frame rate or delayed tick.
- Bot count higher than visible actor budget.

## Failure Condition

If bots do not carry value, combat becomes detached from extraction stakes.
