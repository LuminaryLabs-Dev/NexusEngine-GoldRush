# Gold Rush Feedback Bugs

- One visible issue per bug file.
- Keep the bug open until a screenshot, Playwright run, or validator proves it is fixed.
- Tie every bug to the current player impact, likely source files, and next local GoldRush-only action.
- Do not close bugs from code intent alone.
