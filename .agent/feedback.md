# Feedback

Status: active

## Purpose

Short index for active feedback themes.

Older screenshot/live-playtest bug packets live in `.agent/feedback/`.
Chat-level direction packets live in `.agent/feedback-packets/`.

## Active Themes

- Terrain grounding, visible terrain parity, and physics reliability.
- Character readability, knees, animation, and camera authority.
- Loading-yard train movement, boarding, and party handoff reliability.
- Sanitized asset import, approval, and runtime promotion boundaries.
- Local/public live-state drift must be checked with screenshots on both targets; use video capture when judging movement, camera, pulsing, train, or interaction timing.
- World and terrain must read as a large playable environment, not a circular arena or one reference image.
- Procedural content is acceptable only when represented as domain-scoped object protokits.
- Interaction and visuals should move toward a clean player-facing action surface instead of debug shortcuts.
- GPT-it/cloud work should explain intent and source evidence before being asked to execute work.
